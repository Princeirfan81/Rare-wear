RARE WEAR ONLINE ADMIN

GitHub Pages hosts the site. Supabase provides products, admin login and product image storage.

1. Put your Supabase Project URL and Publishable key in assets/config.js.
2. Upload this folder's contents to the root of the GitHub repo, replacing old files.
3. Keep GitHub Pages on main / root.
4. Open your live site and choose Admin.
5. Sign in with the Supabase admin user.

Never put a Supabase secret/service_role key or an admin password in this public repository.
