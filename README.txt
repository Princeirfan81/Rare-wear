IMPORTANT ABOUT FREE HOSTING
A normal static host (GitHub Pages/Netlify/Cloudflare Pages) cannot let a browser securely write files back to the server. Therefore this ZIP includes a practical admin editor that lets you edit products and DOWNLOAD an updated products.json. Replace the old data/products.json in your site files with the downloaded file and re-upload.

For a true online admin system where you log in from your phone and changes immediately appear on the live website, the site needs a backend/database or a CMS. That is the next step if you want fully automatic online product management.

HOW TO USE
1. Extract the ZIP.
2. Open index.html for the website.
3. Open admin/index.html for the admin panel.
4. Add product photos inside assets/products/.
5. In the admin panel, enter the image path, e.g. assets/products/mug.jpg.
6. Edit name/price/description.
7. Click "Download updated products.json".
8. Replace data/products.json with that downloaded file.
9. Upload the complete folder again to your hosting service.
